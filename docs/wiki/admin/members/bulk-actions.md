# Members Bulk Actions

> Audience: Admins

![Members bulk action toolbar](/uploads/wiki-dashboard/operations/members-bulk-actions.png)

## What This Is

Bulk actions apply changes to multiple selected member records. They are powerful and should be used only after careful row selection.

## When To Use It

- A confirmed group needs the same tag, qualification, status, or archive action.
- The filtered result set has been verified.
- A controlled roster maintenance task affects multiple records.

## What To Check

- Every selected row belongs in the change.
- Filters are not hiding selected rows on another page.
- The action has permission and evidence behind it.

## Step-By-Step Procedure

1. Filter to the intended group.
2. Select rows deliberately.
3. Review the selected count.
4. Choose the bulk action.
5. Review modal details before saving.
6. Confirm results and clear selection.

## Good / Caution / Stop Conditions

Good: All selected rows needed the same change and the result is consistent.

Caution: Bulk action mistakes are harder to notice than single-row edits.

Stop: Do not bulk edit from a broad unreviewed search result.

## Confirm After Action

- Selected count returns to zero or expected state.
- Sample rows show the intended update.
- Downstream effects are checked when needed.

## When To Escalate

Escalate if a bulk change applies to the wrong group or partially fails.
