# Member Records

> Audience: Admins and authorized managers

![Members page overview](/uploads/wiki-dashboard/operations/members-overview.png)

## What This Is

Member Records is the personnel administration area for Sentinel. It controls roster identity, status, badge relationships, qualifications, tags, and access details used by other pages.

## When To Use It

- Add or update personnel records.
- Check whether a member is active, hidden, archived, or civilian staff.
- Prepare records for badges, schedules, reports, or qualifications.

## What To Check

- Sentinel says the record identity, division, status, and badge state.
- The real personnel source confirms who the person is and what access they should have.
- You have permission to make the change.

## Step-By-Step Procedure

1. Search before creating a record.
2. Open the exact row before editing.
3. Use row actions for record-specific changes.
4. Use bulk actions only after selecting every intended row.
5. Run qualification sync after major roster changes when needed.

## Good / Caution / Stop Conditions

Good: Records match the current authorized personnel source.

Caution: Member changes can affect login, scheduling, badge use, and reporting.

Stop: Do not create duplicate records or assign access from an unverified source.

## Confirm After Action

- The row shows the expected name, status, division, badge state, and tags.
- Downstream pages such as Schedules or Dashboard show the expected effect.

## When To Escalate

Escalate if official personnel data and Sentinel disagree.
