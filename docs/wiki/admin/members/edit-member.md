# Edit Member

> Audience: Admins

![Member edit form](/uploads/wiki-dashboard/operations/members-create-member.png)

## What This Is

Edit Member changes an existing personnel record. Use it to keep Sentinel aligned with the current authorized personnel source.

## When To Use It

- Rank, division, contact, status, badge, or access fields need correction.
- A member changes role or becomes inactive.
- A record needs cleanup after import.

## What To Check

- Sentinel says the current record values.
- The real personnel source says what should be current.
- The change will not unexpectedly affect schedules, badge access, or reporting.

## Step-By-Step Procedure

1. Find the exact row.
2. Open Edit.
3. Change only the fields that are confirmed.
4. Save and re-open the row if needed to verify.
5. Check related pages when the change affects operations.

## Good / Caution / Stop Conditions

Good: The record matches the current source and downstream pages behave as expected.

Caution: Status and badge changes can affect login and check-in behavior.

Stop: Do not edit one person when you meant another similar name.

## Confirm After Action

- The table row reflects the saved change.
- Qualifications, tags, and badge state still make sense.

## When To Escalate

Escalate if the change may remove access during active operations.
