# Create Member

> Audience: Admins

![Create member form](/uploads/wiki-dashboard/operations/members-create-member.png)

## What This Is

Create Member adds a nominal-roll personnel record that Sentinel can use for badges, qualifications, schedules, History, and reports.

## When To Use It

- A new authorized member must be added.
- A member exists in the official source but not Sentinel.
- A record must be created before badge or scheduling work.

## What To Check

- Service number, rank, first and last name.
- Division and active status.
- Badge fields only when authorized.

## Step-By-Step Procedure

1. Search the roster for existing records first.
2. Open New Member.
3. Enter identity fields from the trusted source.
4. Assign division and status.
5. Save the record.
6. Add badge, qualifications, or tags only when those details are confirmed.

## Good / Caution / Stop Conditions

Good: One accurate record exists for the member.

Caution: A duplicate member can break history and schedules.

Stop: Do not create a member from memory or unofficial notes.

## Confirm After Action

- The new row appears in Members.
- The member can be found by search.
- Downstream pages show the member only where expected.

## When To Escalate

Escalate if the official source has conflicting identity details.
