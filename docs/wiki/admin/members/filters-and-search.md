# Members Filters And Search

> Audience: Admins and authorized managers

![Members filters and search controls](/uploads/wiki-dashboard/operations/members-filters.png)

## What This Is

Filters and search help find the right personnel record before you edit, archive, or include it in a bulk change.

## When To Use It

- The roster is large.
- You need a division, status, qualification, or name subset.
- You are preparing bulk changes.

## What To Check

- Search spelling.
- Scope such as nominal roll, civilian staff, or all.
- Division, rank, status, and qualification filters.

## Step-By-Step Procedure

1. Search by name or service number first.
2. Add filters one at a time.
3. Review the result count and visible rows.
4. Clear filters before deciding a member does not exist.
5. Keep the filter set visible while performing bulk actions.

## Good / Caution / Stop Conditions

Good: The intended record or group is visible with no unrelated rows selected.

Caution: Filters can hide archived or civilian staff records.

Stop: Do not create a new record before clearing filters and checking alternate spellings.

## Confirm After Action

- The selected record identity matches the source document.
- The row count makes sense for the task.

## When To Escalate

Escalate if an expected active member cannot be found.
