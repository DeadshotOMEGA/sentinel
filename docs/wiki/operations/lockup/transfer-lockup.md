# Transfer Lockup

![Transfer lockup responsibility](/uploads/wiki-dashboard/operations/dashboard-action-transfer-lockup.png)

## What This Is

Transfer lockup responsibility to a confirmed eligible member.

## When To Use It

Use this page when the visible Sentinel workflow matches this topic and you need the current operator-facing steps.

## What To Check

- Confirm the page, panel, or modal title matches the task you are performing.
- Confirm the selected person, date, duty role, or system area before saving changes.
- Confirm Sentinel state matches the real building and current duty expectations.

## Procedure

1. Open the matching Sentinel page or Dashboard control.
2. Confirm you are using the correct workstation and signed-in account.
3. Review the visible state before changing anything.
4. Complete the smallest action needed for the current duty task.
5. Recheck the Dashboard, table, or status panel after the action completes.

## Good / Caution / Stop

Good: The visible Sentinel state, operator expectation, and real-world condition agree.

Caution: The control is available but the surrounding status needs another check.

Stop: Identity, responsibility, building state, or duty coverage is unclear. Resolve or escalate before continuing.

## When To Escalate

Escalate if Sentinel does not update after the action, if a required control is missing, or if the displayed responsibility conflicts with the real-world duty handoff.
