# Create Event

> Audience: Event planners and admins

![Create event form](/uploads/wiki-dashboard/operations/events-create-event.png)

## What This Is

Create Event adds a planned activity to Sentinel so the unit can track status and supporting duties.

## When To Use It

- A new event is approved for planning.
- DDS or schedulers need visibility before the event date.
- Event Duty Watch may be required.

## What To Check

- Title, date, time, location, event type, and category.
- Whether Duty Watch support is required.
- Any notes that help DDS or schedulers understand the event.

## Step-By-Step Procedure

1. Open New Event.
2. Enter the event name and timing from the official plan.
3. Choose the correct type and category.
4. Set Duty Watch requirement if support is needed.
5. Save as draft or planned according to local workflow.
6. Open detail and verify the created record.

## Good / Caution / Stop Conditions

Good: The event is findable and contains enough detail to support planning.

Caution: Incomplete event details create schedule confusion.

Stop: Do not create an event without a real planned activity behind it.

## Confirm After Action

- The event appears in the list.
- The detail page shows the expected status and Duty Watch need.

## When To Escalate

Escalate if required fields are unknown or the event owner is unclear.
