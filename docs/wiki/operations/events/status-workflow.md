# Event Status Workflow

> Audience: Event planners and admins

![Event status workflow buttons](/uploads/wiki-dashboard/operations/events-status-workflow.png)

## What This Is

Event status tells Sentinel where an event sits in the planning lifecycle.

## When To Use It

- Move an event from draft to planned, confirmed, in progress, complete, cancelled, or postponed.
- Explain why an event is or is not ready for Duty Watch support.
- Close out completed or cancelled event records.

## What To Check

- Sentinel says the current status.
- The real event owner confirms the next status.
- Duty Watch assignments are not being left behind by a cancellation or postponement.

## Step-By-Step Procedure

1. Open the event detail page.
2. Confirm event identity and current status.
3. Choose the next valid status action.
4. Save or confirm the status change.
5. Review list and detail status after the update.
6. Notify schedulers if the status affects support duties.

## Good / Caution / Stop Conditions

Good: Status reflects the real event lifecycle.

Caution: Cancelling or postponing can affect assigned duties.

Stop: Do not mark confirmed, complete, or cancelled without owner confirmation.

## Confirm After Action

- The new status badge is visible.
- Duty Watch requirements still make sense.

## When To Escalate

Escalate if an event has assignments but the event is cancelled or postponed.
