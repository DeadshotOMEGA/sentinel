# Event Detail

> Audience: Event planners, DDS, admins

![Event detail page with overview and Duty Watch sections](/uploads/wiki-dashboard/operations/events-detail.png)

## What This Is

Event Detail is the single source page for one event. It shows status, overview fields, action controls, and Duty Watch planning.

## When To Use It

- Before changing event status.
- Before assigning event Duty Watch.
- When DDS needs to understand event support requirements.

## What To Check

- Sentinel says the current event status and details.
- The real event plan confirms the same status and details.
- Duty Watch tab is reviewed when support is required.

## Step-By-Step Procedure

1. Open the event from the list.
2. Read the title, date, status, and category.
3. Review overview fields.
4. Open Duty Watch when support is required.
5. Use action buttons only after confirming the event identity.

## Good / Caution / Stop Conditions

Good: The detail page matches the current plan.

Caution: Action buttons affect the whole event record.

Stop: Do not update the wrong event with a similar title or date.

## Confirm After Action

- Status badge, overview, and Duty Watch tab all match expectations.
- Schedulers have enough information to plan support.

## When To Escalate

Escalate if the event plan changed but the correct update is unclear.
