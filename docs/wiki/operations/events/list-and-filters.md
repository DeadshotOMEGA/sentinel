# Events List And Filters

> Audience: Event planners and admins

![Event filters and list table](/uploads/wiki-dashboard/operations/events-filters-list.png)

## What This Is

The Events list and filters help find planned, confirmed, completed, cancelled, or postponed events.

## When To Use It

- The list contains many events.
- You need a category, status, or date range.
- You are checking whether an event already exists.

## What To Check

- Category, status, start date, and end date.
- The event row title and date.
- Whether Duty Watch is required.

## Step-By-Step Procedure

1. Choose category only when it is known.
2. Filter by status for planning workflow.
3. Set date range around the expected event.
4. Review rows before creating a duplicate.
5. Clear filters if the event is not found.

## Good / Caution / Stop Conditions

Good: The target event is found or confidently confirmed missing.

Caution: A postponed or cancelled event can be hidden by status filters.

Stop: Do not create a duplicate event because filters hid the original.

## Confirm After Action

- The row status and date match the real event plan.
- Duty Watch requirement is visible before scheduling support.

## When To Escalate

Escalate if no event owner can confirm whether a similar event is duplicate.
