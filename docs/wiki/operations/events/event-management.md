# Event Management

> Audience: Event planners, DDS, admins

![Events page overview](/uploads/wiki-dashboard/operations/events-overview.png)

## What This Is

Event Management records planned activities that can affect attendance, schedules, and Duty Watch support.

## When To Use It

- Create or review unit events.
- Confirm event timing, location, category, and status.
- Plan event-specific Duty Watch support.

## What To Check

- Sentinel says the event title, date, status, category, and support requirement.
- The real event plan confirms the same details.
- Schedules have enough lead time to support the event.

## Step-By-Step Procedure

1. Open Events from the navbar.
2. Filter to the relevant period or status.
3. Open the event detail before changing status.
4. Create events before assigning event Duty Watch.
5. Update changed details as soon as they are known.

## Good / Caution / Stop Conditions

Good: Event records match the current plan and support duties can be scheduled.

Caution: Outdated event times can create wrong duty expectations.

Stop: Do not mark an event confirmed if the real event is not confirmed.

## Confirm After Action

- The list and detail page show the expected status.
- Schedules and DDS notes use the same event information.

## When To Escalate

Escalate if event timing or support requirements are disputed.
