# Edit Cancel Or Delete Event

> Audience: Event planners and admins

![Event edit and delete action controls](/uploads/wiki-dashboard/operations/events-edit-cancel-delete.png)

## What This Is

Event action controls change or remove event records. They should be used only after confirming the event identity and operational effect.

## When To Use It

- Event details change.
- An event is cancelled or postponed.
- A duplicate draft event needs removal.

## What To Check

- The event title and date are correct.
- The real event owner authorized the change.
- Any Duty Watch or schedule impact is understood.

## Step-By-Step Procedure

1. Open the exact event detail page.
2. Use Edit for detail changes.
3. Use status actions for cancellation or postponement when available.
4. Delete only draft or duplicate records according to permission.
5. Confirm the list no longer shows incorrect information.

## Good / Caution / Stop Conditions

Good: The event record now matches the real plan and no assignments are orphaned.

Caution: Deleting removes an audit trail from normal operator view.

Stop: Do not delete an event that has operational history or unresolved assignments.

## Confirm After Action

- The list and detail page show the expected result.
- Schedulers are told when support duties changed.

## When To Escalate

Escalate if a non-draft event needs deletion or has active assignments.
