# Daily Start: DDS

DDS means Duty Day Staff for the current day.

## Procedure

1. Confirm the assigned DDS name.
2. Confirm the DDS is on site when expected.
3. Complete or transfer handover if Sentinel shows a pending handover.
4. Escalate if DDS is missing or unclear.

## Admin Action

Do not continue routine control actions while DDS responsibility is unresolved.
