# Daily Start: DDS

![DDS status block in the status panel](/uploads/wiki-dashboard/operations/dashboard-status-panel-focus.png)

DDS means Duty Day Staff: the person responsible for the day's duty coordination in Sentinel.

## What This Is

DDS means Duty Day Staff: the person responsible for the day's duty coordination in Sentinel.

## When To Use It

Use it during daily start before relying on duty, building, or lockup status.

## What To Check

- A DDS is assigned.
- The assigned DDS is expected for today.
- The DDS is on site when required.
- Any handover state is resolved or understood.

## Step-by-Step Admin Procedure

1. Read the DDS name in the status panel.
2. Confirm the person is the expected Duty Day Staff member.
3. Check whether Sentinel says they are on site.
4. If handover is pending, complete or transfer it only after confirming the incoming DDS.
5. Escalate if DDS responsibility is unclear.

## Good / Caution / Stop Conditions

Good: DDS is assigned, expected, and on site when required.

Caution: DDS is assigned but not yet checked in.

Stop: No DDS is assigned, the wrong person is shown, or handover is disputed.

## What To Confirm After Action

After transfer or handover, confirm the DDS block shows the correct person and state.

## When To Escalate

Escalate missing DDS coverage before routine control actions continue.
