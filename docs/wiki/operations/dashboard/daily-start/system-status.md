# Daily Start: System Status

Start the day by checking whether Sentinel is healthy.

## Procedure

1. Confirm the System Status pill reads Healthy.
2. If not Healthy, open the dropdown.
3. Review database, backend, frontend, wiki, network, connected systems, updates, uptime, and last check.
4. Refresh once if the dashboard looks stale.

## Escalate When

- Database or backend is unavailable.
- Network status is warning or error.
- Last check time is stale.
- Connected systems are missing when expected.
