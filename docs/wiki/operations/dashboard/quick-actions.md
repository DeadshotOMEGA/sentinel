# Dashboard Quick Actions

Quick Actions change live operational state.

## Actions

- Open Building: records that the building has been opened under a responsible member.
- Execute Lockup: records that the building has been secured.
- Transfer DDS: moves or completes Duty Day Staff responsibility.
- Transfer Lockup: hands lockup responsibility to another qualified checked-in member.
- Manual in/out: corrects attendance when scanning did not happen.

## Admin Action

Before pressing an action, confirm status blocks and the real-world condition agree.
