# User Menu

![User menu area in the Dashboard navbar](/uploads/wiki-dashboard/operations/dashboard-nav-user-menu.png)

The user menu shows who is signed in and provides account/session actions.

## What This Is

The user menu identifies the signed-in operator and provides account actions such as changing PIN or signing out.

## When To Use It

Check this before making Admin changes, before lockup-related actions, and whenever you return to a shared workstation.

## What To Check

- The displayed member is the person currently operating Sentinel.
- The access level matches the task you are about to perform.
- The session belongs to you, not the previous operator.

## Admin Procedure

1. Look at the user menu before high-impact actions.
2. Confirm you are signed in as yourself.
3. Change PIN only for your own account maintenance.
4. Sign out when leaving the workstation or handing it to another person.

## Shared Workstation Reminder

DDS and Admin workstations may be used by more than one person during the day. Always sign out before leaving the desk, and never perform lockup, transfer, or correction actions under another person's session.

## Good / Caution / Stop

Good: The signed-in user and role match the operator and task.

Caution: You are using a shared workstation after someone else was signed in.

Stop: The session belongs to another person.

## When To Escalate

Escalate if account details look wrong, if you cannot sign out, or if access level does not match your assigned responsibility.
