# Dashboard Help Button

The Help button opens the best help target for the current page.

## Normal Use

- On Dashboard, it starts the Dashboard orientation tour.
- During a guided step, it changes to step help and opens the page for the active step.
- If the wiki is unavailable, Sentinel falls back to local quick help.

## Admin Action

Use Help before guessing. Guided steps are written for normal Admin users and explain the order of checks.
