# Dashboard Help Button

![Help button beside System Status](/uploads/wiki-dashboard/operations/dashboard-navbar-overview.png)

The Help button starts Dashboard-specific guidance. During a tour, it opens help for the active guided step.

## What This Is

The Help button is the fastest way to get context for the Dashboard. It opens grouped guided procedures and links each step to a detailed Wiki page.

## When To Use It

Use Help when you are new, when you are unsure what to check next, when an action is disabled, or before you perform a high-impact action for the first time.

## What To Check

- If no tour is active, Help opens the Dashboard help menu.
- If a guided step is active, Help opens the Wiki page for that specific step.
- If Wiki is unavailable, Sentinel should fall back to local quick help.

## Admin Procedure

1. Select Help from the navbar.
2. Choose the procedure that matches your task: orientation, daily start, daily end, status, Presence, or actions.
3. Move through the popovers one step at a time.
4. Use the step help link when you need more detail than the popover gives.
5. Close the tour when you are done or press Escape if you need to return to the Dashboard immediately.

## Good / Caution / Stop

Good: You can open Help and reach the matching Wiki page.

Caution: A tour step points at a section that is hidden because the current state has no matching data.

Stop: You cannot reach Wiki and local fallback help does not open.

## When To Escalate

Escalate if Help opens the wrong procedure, if a Learn more link fails, or if the Dashboard tour highlights the wrong area.
