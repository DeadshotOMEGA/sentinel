# Security Alerts

Security alerts are the first Dashboard item to review.

## What They Mean

Alerts can represent missed checkouts, badge issues, inactive members, unauthorized access, missing Duty Watch coverage, or lockup problems.

## Admin Action

1. Read the alert type and message.
2. Confirm the real-world situation.
3. Correct or escalate the issue.
4. Acknowledge only after action is taken.

Acknowledgement is not a dismissal. It is the record that the issue was handled.
