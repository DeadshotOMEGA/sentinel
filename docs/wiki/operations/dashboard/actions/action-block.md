# Actions: Action Block

![Dashboard action block](/uploads/wiki-dashboard/operations/dashboard-quick-actions-focus.png)

The action block contains controls that change live responsibility, building state, or attendance.

## What This Is

The action block contains controls that change live responsibility, building state, or attendance.

## When To Use It

Use it only after reviewing alerts, status, and Presence.

## What To Check

- Which action is available.
- Which status block the action will change.
- Whether real-world conditions match Sentinel.
- Whether you have authority to make the change.

## Common DDS Actions That Start Here

- [Transfer DDS](/operations/day-duty/transfer-dds) when Duty Day Staff responsibility is changing.
- [Transfer Lockup](/operations/day-duty/transfer-lockup) when the current lockup holder is leaving or handing off.
- [Execute Lockup](/operations/day-duty/execute-lockup) only after alerts, visitors, remaining people, and holder identity are resolved.

## Step-by-Step Admin Procedure

1. Read the status panel first.
2. Confirm the real-world condition.
3. Select only the required action.
4. Complete notes or confirmation prompts.
5. Recheck status and Presence.

## Good / Caution / Stop Conditions

Good: Action matches current state and authority.

Caution: Action is disabled because a condition is missing.

Stop: You are using an action to hide a mismatch.

## What To Confirm After Action

Confirm the affected status block changed.

## When To Escalate

Escalate failed or disputed actions.
