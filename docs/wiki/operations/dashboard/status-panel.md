# Status Panel

The status panel answers the operational questions Admin users need before acting.

## Blocks

- DDS: who is Duty Day Staff and whether handover is needed.
- Duty Watch: scheduled and checked-in coverage.
- Building: whether Sentinel believes the building is open or secured.
- Lockup Holder: who currently owns lockup responsibility.
- Actions: controls available for the current state and permission.

## Admin Action

Read left to right before using any action. If any block disagrees with reality, stop and escalate.
