# Status Panel

![Status panel with DDS, Duty Watch, Building, Lockup Holder, and actions](/uploads/wiki-dashboard/operations/dashboard-status-panel-focus.png)

The status panel answers the core operational questions before an Admin acts.

## What This Is

The status panel summarizes responsibility and readiness. Read it left to right before using Dashboard actions.

## When To Use It

Use it before daily start decisions, lockup, DDS transfer, lockup transfer, manual attendance corrections, or escalation calls.

## What To Check

- DDS: who is Duty Day Staff and whether they are on site.
- Duty Watch: assigned, checked-in, uncovered, and live-only coverage.
- Building Status: whether Sentinel believes the building is open, secured, or in transition.
- Lockup Holder: who currently owns lockup responsibility and since when.
- Actions: which controls are valid for the current state and permissions.

## Admin Procedure

1. Start with DDS and resolve missing or unclear responsibility.
2. Check Duty Watch coverage for gaps.
3. Compare Building Status with the real building.
4. Confirm Lockup Holder identity before transfers, checkout, or lockup.
5. Use actions only when each status block agrees with reality.

## Good / Caution / Stop

Good: Each block matches the real building, people, and duty expectations.

Caution: A block is technically valid but does not match what the watch team expects.

Stop: Building Status or Lockup Holder disagrees with the real-world condition.

## What To Confirm After Action

After any action, recheck the status block that should have changed and then confirm the result in Presence.

## When To Escalate

Escalate if a status block does not update, if an action is disabled for unclear reasons, or if responsibility is disputed.
