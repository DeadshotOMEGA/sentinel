# Navbar Navigation

![Dashboard navbar navigation links](/uploads/wiki-dashboard/operations/dashboard-navbar-overview.png)

The navbar is the map for Admin work. Use Dashboard for live operations and the other sections for records, planning, procedures, and configuration.

## What This Is

The navbar links move you between Sentinel work areas. The Dashboard is for live decisions. Other sections support records, planning, member administration, procedures, and system configuration.

## When To Use It

Use the navbar when your question is no longer a live Dashboard question. For example, use History for past check-ins, Members for records, Schedules for duty planning, Wiki for procedures, and Admin for configuration.

## What To Check

- Dashboard: live alerts, status, actions, and Presence.
- History: past check-ins, corrections, and attendance review.
- Members: member records, tags, qualifications, and badges.
- Events and Schedules: planned activity and duty coverage.
- Wiki: procedures and reference help.
- Admin: configuration, updates, logs, and technical tools.

## Admin Procedure

1. Stay on Dashboard while making live operational decisions.
2. Move to History when you need evidence of past attendance.
3. Move to Members when the issue is a record, badge, qualification, or member profile.
4. Move to Schedules when the issue is planned duty coverage.
5. Move to Wiki when you need written procedure detail.
6. Move to Admin only for configuration or technical maintenance.

## Good / Caution / Stop

Good: You are using Dashboard for live state and other pages for supporting records.

Caution: You are about to make a live decision based only on History or Members without checking Dashboard.

Stop: You are changing configuration to work around a live operational mismatch.

## When To Escalate

Escalate if a navbar section is unavailable, if Wiki is unreachable during operations, or if records in another section contradict Dashboard status.
