# Navbar Navigation

The navbar is the map for Admin work.

## Main Destinations

- Dashboard: live operations, status, alerts, and presence.
- History: past check-ins, visitor records, and corrections.
- Members: member records, qualifications, tags, and badges.
- Events and Schedules: planned activity and duty coverage.
- Wiki: procedures and reference pages.
- Admin: configuration, updates, logs, database review, and system tools.

## Admin Action

Use Dashboard for live decisions. Use the other sections when you need records, planning, or configuration detail.
