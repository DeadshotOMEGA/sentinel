# Navbar Brand

![Navbar brand and environment badge](/uploads/wiki-dashboard/operations/dashboard-navbar-overview.png)

The left side of the navbar identifies the Sentinel appliance you are operating.

## What This Is

The brand area shows the unit or ship name and the environment badge. It is your first confirmation that you are working in the correct Sentinel system before changing attendance, DDS, building, or lockup state.

## When To Use It

Check this every time you start a shift, use a shared workstation, return from another browser tab, or take a screenshot for escalation.

## What To Check

- The unit or ship name matches the building you are operating.
- The environment badge matches the expected appliance or server.
- The page is not a test, old, or unexpected environment.

## Admin Procedure

1. Look at the brand text before using Dashboard controls.
2. Confirm the server/environment badge with the workstation you intended to use.
3. If the name or badge looks wrong, stop before pressing actions.
4. Include this area in screenshots when reporting dashboard problems.

## Good / Caution / Stop

Good: The brand and badge match the expected Sentinel appliance.

Caution: You are unsure whether the browser is pointed at the appliance or a local/test server.

Stop: The brand or environment is not the system you meant to operate.

## When To Escalate

Escalate if operators are being routed to the wrong Sentinel appliance or if two browser tabs show conflicting environments.
