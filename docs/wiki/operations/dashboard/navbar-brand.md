# Navbar Brand

Use the brand area first to confirm you are working in the correct Sentinel appliance.

## What to Check

- Unit name matches the building or ship you are operating.
- Server badge matches the expected host, such as deployment laptop or local server.
- If the name or server badge looks wrong, stop before changing attendance or lockup state.

## Admin Action

Tell the watch team which appliance you are using when reporting a problem. Screenshots should include this area when possible.
