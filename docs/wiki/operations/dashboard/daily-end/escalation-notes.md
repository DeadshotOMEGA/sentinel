# Daily End: Escalation Notes

![Dashboard context for end-of-day notes](/uploads/wiki-dashboard/operations/dashboard-overview-main.png)

Escalation notes leave enough context for the next operator to understand unresolved issues.

## What This Is

Escalation notes leave enough context for the next operator to understand unresolved issues.

## When To Use It

Use it when anything remains mismatched, unresolved, or handed off at end of day.

## What To Check

- What looked wrong.
- Who was involved.
- Which action was attempted.
- Current building and lockup state.
- Whether any alerts remain.

## Step-by-Step Admin Procedure

1. Write the issue in plain language.
2. Include the current Dashboard status.
3. Include who accepted the handoff or escalation.
4. Capture a screenshot if helpful.
5. Sign out only after the issue is corrected, handed off, or escalated.

## Good / Caution / Stop Conditions

Good: The next operator can understand the state without guessing.

Caution: The issue is handled verbally but not written down.

Stop: You are about to leave with unresolved state and no handoff.

## What To Confirm After Action

Confirm the receiving person has the note or escalation details.

## When To Escalate

Escalate before signing out if the state is unresolved.
