# Daily End: Security Alerts

![Security alerts reviewed before end-of-day lockup](/uploads/wiki-dashboard/operations/dashboard-security-alerts-active.png)

End-of-day alerts must be reviewed before lockup, handoff, or sign-out.

## What This Is

End-of-day alerts must be reviewed before lockup, handoff, or sign-out.

## When To Use It

Use it before checking remaining people and before executing lockup.

## What To Check

- All active alerts are read.
- Each alert was handled, corrected, or escalated.
- Acknowledgement notes are clear.
- Unresolved alerts are not hidden by lockup actions.

## Step-by-Step Admin Procedure

1. Review every active alert.
2. Confirm whether it is still true.
3. Add a clear acknowledgement note only after action.
4. Escalate anything unresolved before leaving.

## Good / Caution / Stop Conditions

Good: No active alert remains without context.

Caution: An alert is present but may already have been handled by someone else.

Stop: An unresolved alert affects building security, people on site, or lockup.

## What To Confirm After Action

Confirm the alert area updates and any related status changes are visible.

## When To Escalate

Escalate unresolved alerts before leaving the workstation.
