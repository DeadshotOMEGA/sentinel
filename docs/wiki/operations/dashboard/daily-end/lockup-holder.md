# Daily End: Lockup Holder

The lockup holder is responsible for securing the building.

## Procedure

1. Confirm the holder name in Sentinel.
2. Confirm the same person is actually accepting responsibility.
3. Check how long the holder has held lockup.
4. Transfer lockup if responsibility is moving to someone else.

## Admin Action

Never execute or transfer lockup based only on memory. Confirm the current holder.
