# Daily End: Duty Handoff

![Duty Watch block used for handoff checks](/uploads/wiki-dashboard/operations/dashboard-stat-duty-watch.png)

Duty handoff confirms the next responsible person understands the current Dashboard state.

## What This Is

Duty handoff confirms the next responsible person understands the current Dashboard state.

## When To Use It

Use it before signing out, before lockup, or when responsibility is moving to another operator.

## What To Check

- DDS handover state is known.
- Evening Duty Watch coverage is known.
- Uncovered positions are resolved or escalated.
- The next responsible person accepts the current state.

## Step-by-Step Admin Procedure

1. Read DDS and Duty Watch status.
2. Confirm evening expectations with the receiving person.
3. Resolve or document uncovered positions.
4. Explain any active alerts or mismatches.
5. Confirm the handoff is accepted.

## Good / Caution / Stop Conditions

Good: The next responsible person knows the current state and next action.

Caution: Coverage is technically present but not the expected person.

Stop: Responsibility is unclear or nobody accepts the handoff.

## What To Confirm After Action

Confirm status blocks and notes match the handoff.

## When To Escalate

Escalate if no responsible person accepts the current state.
