# Daily End: Duty Handoff

Confirm DDS and Duty Watch expectations before closing the day.

## Procedure

1. Confirm DDS handover state.
2. Confirm evening Duty Watch coverage.
3. Resolve uncovered positions or document the escalation.
4. Make sure the next responsible person understands the current status.

## Admin Action

Handoff is not complete until the next responsible person has accepted the state.
