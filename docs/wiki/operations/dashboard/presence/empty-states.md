# Presence: Empty States

![Presence grid empty or filtered state](/uploads/wiki-dashboard/operations/dashboard-presence-grid-focus.png)

Empty states explain whether nobody is checked in or filters/search are hiding results.

## What This Is

Empty states explain whether nobody is checked in or filters/search are hiding results.

## When To Use It

Use it when Presence looks empty or does not show the person you expect.

## What To Check

- Whether filters are active.
- Whether search is active.
- Whether data is still loading.
- Whether System Status is Healthy.

## Step-by-Step Admin Procedure

1. Clear search.
2. Select All.
3. Refresh once if data looks stale.
4. Check System Status if Presence still does not load.

## Good / Caution / Stop Conditions

Good: Empty state matches the real building state.

Caution: Filters or search may be hiding people.

Stop: Real people are present but Sentinel shows none.

## What To Confirm After Action

Confirm after clearing filters and refreshing.

## When To Escalate

Escalate if Presence remains unavailable or wrong.
