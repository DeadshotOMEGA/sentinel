# Presence: Manual In/Out

![Manual in/out correction modal](/uploads/wiki-dashboard/operations/dashboard-manual-in-out-modal.png)

Manual in/out corrects attendance when scanning did not happen or a record needs authorized correction.

## What This Is

Manual in/out corrects attendance when scanning did not happen or a record needs authorized correction.

## When To Use It

Use it only when an authorized operator confirms the correction.

## What To Check

- Correct person.
- Correct direction: in or out.
- Correct time.
- Clear correction reason.

## Step-by-Step Admin Procedure

1. Open Manual in/out.
2. Search and select the correct person.
3. Choose the correct direction.
4. Enter a clear reason.
5. Save the correction.
6. Recheck Presence and History.

## Good / Caution / Stop Conditions

Good: Correction matches the real attendance event and reason is clear.

Caution: The correction is likely valid but details are incomplete.

Stop: The correction is disputed or being used for convenience.

## What To Confirm After Action

Confirm Presence and History reflect the correction.

## When To Escalate

Escalate disputed or unclear manual corrections.
