![Presence filters and counts](/uploads/wiki-dashboard/operations/dashboard-presence-filters.png)

## What This Is

Filters narrow the live list so Admins can separate members, visitors, and all people on site.

## When To Use It

Use filters whenever the Presence list is crowded or you need to review one person type.

## What To Check

- All count.
- Members count.
- Visitors count.
- Whether a search term is also active.

## DDS Filter Recipes

- Visitors only: select Visitors before end-of-day visitor review.
- Members only: select Members when checking Duty Watch or DDS coverage.
- Unexpected people: clear search, select All, then scan for visitors or members who should have left.
- Missing person: clear filters first, then search by last name, rank, organization, or duty role.

## Step-by-Step Admin Procedure

1. Check the All count first.
2. Select Members when checking duty staff.
3. Select Visitors before end-of-day visitor review.
4. Clear filters before deciding nobody is present.

## Good / Caution / Stop Conditions

Good: Counts match the expected people on site.

Caution: A filter may be hiding the person you need.

Stop: Counts conflict with real people in the building.

## What To Confirm After Action

Confirm counts after checkout or correction.

## When To Escalate

Escalate count mismatches that remain after clearing filters.
