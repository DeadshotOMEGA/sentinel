# Presence: Search

![Presence search field](/uploads/wiki-dashboard/operations/dashboard-presence-search.png)

Search helps find a person by visible identity details before assuming they are absent.

## What This Is

Search helps find a person by visible identity details before assuming they are absent.

## When To Use It

Use it when a person is expected but not immediately visible.

## What To Check

- Name.
- Rank.
- Division.
- Organization or visitor details.

## Step-by-Step Admin Procedure

1. Clear unnecessary filters.
2. Enter the person's name, rank, division, or organization.
3. Review matching cards.
4. If no match appears, clear search and check the correct filter.

## Good / Caution / Stop Conditions

Good: The expected person appears or is confirmed absent.

Caution: Search is active while filters hide possible matches.

Stop: A person is physically present but cannot be found.

## What To Confirm After Action

Confirm the card and count before taking action.

## When To Escalate

Escalate if a present person cannot be found in Sentinel.
