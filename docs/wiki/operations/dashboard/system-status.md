# System Status

System Status tells you whether Sentinel itself is healthy enough to trust.

## What to Check

- Healthy means the main app checks are passing.
- Warning or error means you should open the dropdown before retrying failed actions.
- Check database, backend API, frontend, wiki, network, connected systems, updates, environment, uptime, and last check time.

## Admin Action

If the dashboard looks stale, refresh once. If it still looks wrong, open System Status and escalate with the visible status details.
