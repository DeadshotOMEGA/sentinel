# Duty Watch Night Overrides

> Audience: Schedulers and admins

![Duty Watch night override controls](/uploads/wiki-dashboard/operations/schedules-night-overrides.png)

## What This Is

Night overrides adjust Duty Watch coverage for a specific night without changing the whole base roster.

## When To Use It

- One night differs because of availability, event support, or special instruction.
- A base member needs replacement only for one night.
- An extra member is needed for a single night.

## What To Check

- The selected night is correct.
- The base roster remains correct for other nights.
- The override reason is understood.

## Step-By-Step Procedure

1. Open the Duty Watch detail for the correct week.
2. Choose the night tab.
3. Remove, replace, or add members only for that night.
4. Review the effective roster.
5. Publish after confirming the exception.

## Good / Caution / Stop Conditions

Good: Only the intended night changes.

Caution: Night-specific changes are easy to miss later.

Stop: Do not use an override when the whole base roster should change.

## Confirm After Action

- The night tab shows the expected effective roster.
- Base tab still shows the normal roster.

## When To Escalate

Escalate if multiple nights need exceptions or the base roster is no longer accurate.
