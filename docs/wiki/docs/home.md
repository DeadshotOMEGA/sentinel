# Sentinel Operations Wiki

This Wiki is the operator help center for Sentinel. Start here when you need to understand what the Dashboard is showing, what to check first, and which actions are safe to take.

![Sentinel Dashboard overview](/uploads/wiki-dashboard/operations/dashboard-overview-main.png)

## Start Here If

- **You are a new Admin:** open [Dashboard Overview](/operations/dashboard/overview), then follow [Navbar Navigation](/operations/dashboard/navbar-navigation), [System Status](/operations/dashboard/system-status), and [Presence Grid](/operations/dashboard/presence-grid).
- **You are starting the day:** use [Daily Start: System Status](/operations/dashboard/daily-start/system-status), then continue through alerts, DDS, Duty Watch, building state, and Presence review.
- **You are closing or handing off:** use [Daily End: Security Alerts](/operations/dashboard/daily-end/security-alerts), then confirm remaining people, lockup holder, lockup action, and building recheck.
- **You need to correct attendance:** use [Presence: Search](/operations/dashboard/presence/search), [Manual In/Out](/operations/dashboard/presence/manual-in-out), and [Member Actions](/operations/dashboard/presence/member-actions).
- **You are about to change responsibility or building state:** read [Quick Actions](/operations/dashboard/quick-actions), [Transfer DDS](/operations/dashboard/actions/transfer-dds), [Transfer Lockup](/operations/dashboard/actions/transfer-lockup), and [Open Or Lockup](/operations/dashboard/actions/open-or-lockup).

## Dashboard Work Order

1. Check [Security Alerts](/operations/dashboard/security-alerts) before changing building or lockup state.
2. Check the status panel: [DDS](/operations/dashboard/status/dds), [Duty Watch](/operations/dashboard/status/duty-watch), [Building State](/operations/dashboard/status/building-state), and [Lockup Holder](/operations/dashboard/status/lockup-holder).
3. Use [Quick Actions](/operations/dashboard/status/quick-action-state) only after the status blocks match the real situation.
4. Confirm the result in [Presence](/operations/dashboard/presence-grid) before you move on.

## Daily Admin Routine

### Start Of Day

- Confirm [System Status](/operations/dashboard/daily-start/system-status) is Healthy.
- Review [Security Alerts](/operations/dashboard/daily-start/security-alerts).
- Confirm [DDS](/operations/dashboard/daily-start/dds) and [Duty Watch](/operations/dashboard/daily-start/duty-watch) coverage.
- Confirm [Building State](/operations/dashboard/daily-start/building-state) and lockup responsibility.
- Review [Presence](/operations/dashboard/daily-start/presence-review) before assuming anyone is missing.

### End Of Day

- Review [Security Alerts](/operations/dashboard/daily-end/security-alerts) and act before acknowledging.
- Check [Remaining People](/operations/dashboard/daily-end/presence-review), including visitors.
- Confirm [Duty Handoff](/operations/dashboard/daily-end/duty-handoff) and [Lockup Holder](/operations/dashboard/daily-end/lockup-holder).
- Use [Execute Lockup](/operations/dashboard/daily-end/execute-lockup) only when the building should be secured.
- Recheck [Building Status](/operations/dashboard/daily-end/building-recheck) and leave [Escalation Notes](/operations/dashboard/daily-end/escalation-notes) if reality and Sentinel do not match.

## Rules Of Use

- Treat Sentinel as an operational record, then compare it against the real building and people in front of you.
- Stop before high-impact actions if alerts, counts, responsibility, or building state do not match reality.
- Escalate unresolved mismatches instead of forcing the Dashboard to look correct.
- Update procedures when the Dashboard behavior changes.
