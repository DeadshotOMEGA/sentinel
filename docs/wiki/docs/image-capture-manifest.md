# Wiki Image Capture Manifest

Track screenshot capture and replacement for temporary placeholders. Dashboard images must use
sanitized demo or staged data, not live operational records.

Run Dashboard captures with:

```bash
FRONTEND_URL=http://localhost:3001 pnpm playwright-cli:capture:dashboard
```

Source images are kept in `docs/wiki/assets/wiki-dashboard/operations/`. Upload the same files to
Wiki.js Assets Manager under `/uploads/wiki-dashboard/operations/`, then keep the Markdown image
links pointed at `/uploads/wiki-dashboard/operations/<filename>`.
